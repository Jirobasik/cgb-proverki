# АБ — Панель проверок личного состава ЦГБ

Веб-приложение для ведения учета проверок документов и личного состава отделов больницы (АБ, ОРП, ОТН, БСМП, Руководящий состав).

## 📋 Возможности
- Учет 5 видов обязательных проверок (Паспорт, Медкнижка, Нарколог, Водит. удостоверение, Личное дело)
- Группировка сотрудников по настраиваемым категориям
- Дисциплинарные взыскания (активные / архив)
- Генерация и копирование итогового отчета
- Разделение прав (Сотрудник, Старший состав, Администратор)
- Автономная работа без сторонних серверов (localStorage)
